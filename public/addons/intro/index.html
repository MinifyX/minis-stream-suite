🎞️ Intro-Sequenz

Intro → Loop 1 („Stream startet“) → Main → Loop 2 → Outro. „Go“ und „Outro“ wechseln immer erst am Ende des laufenden Loop-Durchlaufs, damit der Beat nicht springt. Danach schaltet die Suite auf die Stream-Szene und startet die Musik.

📺 OBS-Browserquelle

In OBS als Browser-Quelle hinzufügen, 1920 × 1080, Haken bei „Audio über OBS steuern“. Nur eine solche Quelle anlegen, sonst läuft das Intro mehrfach.

📁 Medien

📖 Anforderungen an die Dateien
  • Audio: WAV, 48 kHz, 24 bit, eine Datei pro Segment. Loops exakt auf ganze Takte geschnitten, ohne Stille am Anfang oder Ende.
  • Video: ohne Tonspur, 1920 × 1080, dieselbe Framerate für alle (z.B. 60 fps), WebM (VP9) oder MP4 (H.264). So lang wie das Audio.
  • Das Outro inklusive Ausklang als eine Datei exportieren.
  • Zum Ausprobieren: npm run intro:dummy erzeugt Testdateien.

🔗 Webhooks

Pro Phase Adressen (eine pro Zeile), die beim Erreichen per POST { "state", "ts" } benachrichtigt werden – z.B. Home Assistant für DMX-Licht oder Nebel. Wartezeit max. 3 s, Fehler landen nur im Log.
